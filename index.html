VARPAD

VARPAD - a notepad app with the feature of creating variables and using them right in the text

Download and source

You can download source and app itself on the github page

What's coming?

  • More datatypes
  • More mathematical operations
  • Rewritten varlang
  • Config for themes

Compatibility

App is avaliable on windows
(MAC AND LINUX SUPPORT COMING SOON WITH LATER UPDATES)

Controls

F10 - save your text file;
Shift + Scroll - scroll horizontally

VARIABLE CREATION

In the var section (||VAR: ... :END||) you can interact with variables:

  • $name = value (Creates a variable)
  • %name = value (Changes existing variable's value)

VARIABLE TYPES

  • Integer (123)
  • Text ("abc")

OPERATIONS

  • Multiply *
  • Add +
  • Subtract -
  • Divide /

ERRORS

If an error occurs the var section will be red color
and in the "upperbar" text will be displayed with an error message

VAR ALREADY EXISTS!


||VAR:
$apples = 1
$apples = 2
:END||
